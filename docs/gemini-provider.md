# Gemini provider

The first model-backed adapter uses Google's official `@google/genai` JavaScript SDK and the Generate Content API with JSON-schema structured output.

## Safety boundary

The API key is read from `GEMINI_API_KEY` in the process environment or an ignored `.env` file. It is never stored in application configuration. A live request requires an interactive confirmation unless `--yes` is explicitly provided.

## Output contract

Gemini returns structured opening dialogue, one segment for every selected story cluster, and closing dialogue. Each factual exchange carries the database IDs of its supporting sources. Before files are written, the application checks:

- every selected cluster appears exactly once;
- each story segment contains both hosts;
- cited source IDs belong to the relevant cluster;
- the spoken dialogue stays within the configured word limit;
- the returned JSON matches the required schema.

Show notes are rendered locally from stored URLs rather than generated by the model.

## Model selection

`config/editorial.json` currently selects the stable `gemini-3.7-flash` model. Change the model string in that file to test another compatible Gemini model without modifying the adapter.
